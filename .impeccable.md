# SaveFlow Design Context

## Design Context

### Users
SaveFlow serves a mixed audience: creators who need media conversion and transcripts, students/researchers who need searchable summaries, and technical reviewers evaluating the ML/media pipeline. Users may run the app as a hosted SaaS or local low-spec workstation tool.

### Brand Personality
Precise, capable, cinematic. Interface should feel like a media studio operating system: confident, focused, and powerful without becoming noisy or generic.

### Aesthetic Direction
Studio OS: refined media-control-room feel with dark workspace, precise panels, timeline/productivity energy, visible job states, and clear processing status. Avoid generic AI gradients, glowing cyan/purple dark mode, glassmorphism-heavy surfaces, and template SaaS cards.

### Design Principles
1. Make worker/job state visible and understandable at all times.
2. Keep upload-to-output flow simple first, reveal advanced options progressively.
3. Use distinctive studio-grade visual language without sacrificing accessibility.
4. Design mobile as an adapted control surface, not a reduced desktop.
5. Prefer low-motion state transitions and clear feedback over decorative animation.
